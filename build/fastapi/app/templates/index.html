01. Docker Architecture

도커는 클라이언트-서버 아키텍처를 사용합니다. Docker Client가 Docker Daemon과 통신하여 컨테이너를 빌드, 실행, 배포하는 구조를 가집니다.

Docker Daemon (dockerd)
  • 컨테이너, 이미지, 네트워크, 볼륨 관리
  • API 요청 수신 및 처리
  • 다른 데몬과 통신하여 서비스 관리
Docker Client & Registry
  • CLI: 사용자가 도커와 상호작용하는 명령어 인터페이스
  • Docker Hub: 도커 이미지를 보관하고 배포하는 공개/비공개 저장소

02. Docker Components & Tests

Image

Container

Multi-host 오케스트레이션 및 로드 밸런싱 동작을 테스트합니다.

03. Multi-Compose Network

프론트/백엔드 서비스(docker_compose_front.yaml)와 DB 서비스(docker_compose_mysql.yaml)를 공통 네트워크로 연결하는 예시입니다.

# docker_compose_front.yaml
services:
  fastapi-app:
    build: ../build/fastapi
    environment:
      # 컨테이너 이름(mysql_db)으로 통신
      - DATABASE_URL=mysql+pymysql://user:password@mysql_db:3306/mydb
    networks:
      - shared_network

networks:
  shared_network:
    external: true
